HaruPlanner 개인정보처리방침

시행일: 2026년 11월 17일

HaruPlanner(하루플래너)는 할 일 · 일정 · 디데이 · 포스트잇 · 사진 일기를 관리하는 앱이에요. 이 문서는 앱이 어떤 정보를 어디에 저장하고 무엇에 쓰는지 설명해요.

1. 저장하는 정보

  • 계정: 로그인에 쓰는 이메일 주소
  • 내가 만든 데이터: 할 일, 목록, 디데이, 포스트잇, 타이머 기록, 사진 일기(사진과 메모), 앱 설정

이 정보는 여러 기기에서 같은 데이터를 보도록 클라우드 저장소(Supabase)에 저장돼요. 본인 계정으로만 읽고 쓸 수 있어요.

2. 구글 계정 데이터 사용

사용자가 직접 연동을 켠 경우에만 아래 권한을 요청하고, 그 기능에만 써요.

  • 구글 캘린더 (calendar.events, calendar.readonly): 날짜가 있는 할 일과 사용자가 고른 구글 캘린더 일정을 서로 맞추는 데만 써요.
  • 구글 드라이브 앱 전용 폴더 (drive.appdata): 사용자가 정한 비밀번호로 암호화한 백업 파일을 드라이브의 숨김 앱 폴더에 저장하고 되살리는 데만 써요. 드라이브의 다른 파일은 볼 수도, 건드릴 수도 없어요.

HaruPlanner가 구글 API로 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따라요.

  • 구글 데이터를 광고에 쓰지 않아요.
  • 구글 데이터를 팔거나 다른 사람에게 넘기지 않아요.
  • 사람이 구글 데이터를 읽지 않아요. 사용자가 요청한 경우, 보안 · 법적 의무가 있는 경우는 예외예요.
  • 구글 데이터를 AI 모델 학습에 쓰지 않아요.

구글 연동에 필요한 접근 토큰은 서버에만 보관하고, 연동을 끊으면 지워요.

3. 백업 암호화

드라이브 백업과 백업 파일은 사용자가 정한 비밀번호로 기기 안에서 암호화(AES-256-GCM)한 뒤 올라가요. 비밀번호는 서버로 보내지 않아서, 개발자 · 구글 · 클라우드 업체 누구도 백업 내용을 볼 수 없어요. 그래서 비밀번호를 잊으면 백업을 되살릴 수 없어요.

4. 다른 곳에 주는 정보

위의 저장소(Supabase)와 사용자가 켠 구글 연동 외에는 어떤 회사나 사람에게도 정보를 주지 않아요. 광고나 분석 도구도 쓰지 않아요.

5. 지우기와 연동 끊기

  • 앱에서 지운 항목은 저장소에서도 지워져요.
  • 설정에서 구글 캘린더 · 드라이브 연동을 언제든 끊을 수 있어요. 구글 계정 → 서드 파티 연결에서도 끊을 수 있어요.
  • 드라이브의 백업 파일은 앱의 백업 목록에서 지울 수 있어요.
  • 계정과 모든 데이터를 지우고 싶으면 아래 문의처로 알려 주세요.
